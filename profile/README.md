# Arche Linux

Arche Linux is an Arch-based system for keyboard-driven development and local agent workflows. It brings together Neovim, tmux, Sway, and preinstalled language tooling in a focused desktop environment.

The [Arche Linux repository](https://github.com/archelinux/archelinux) contains the ISO profile, installer, packages, configuration, and build instructions. Start with its README to learn how the system is built and installed.

Found a problem or have an idea? [Open an issue](https://github.com/archelinux/archelinux/issues).
